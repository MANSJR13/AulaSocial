# 📚 AulaSocial

Aplicativo mobile desenvolvido em React Native para auxiliar professores que oferecem aulas particulares a preço social em comunidades.

## 🎯 Objetivo

O AulaSocial foi criado para ajudar professores a organizar:

- Cadastro de alunos
- Agenda de aulas
- Relatórios pedagógicos
- Controle financeiro

O projeto surgiu como atividade acadêmica de extensão e também como projeto de portfólio para desenvolvimento mobile.

---

## 🚀 Tecnologias Utilizadas

- React Native
- Expo
- Expo Router
- TypeScript
- Git
- GitHub

---

## 📱 Funcionalidades

### 👨‍🎓 Alunos

- Cadastro de alunos
- Edição de alunos
- Exclusão de alunos
- Listagem de alunos

### 📅 Agenda

- Agendamento de aulas
- Visualização das aulas cadastradas

### 📝 Relatórios

- Registro de observações sobre alunos
- Registro de observações sobre as aulas
- Histórico de relatórios

### 💰 Financeiro

- Cadastro de lançamentos
- Controle de pagamentos
- Status Pago/Pendente
- Dashboard financeiro
- Filtro por aluno
- Filtro por mês
